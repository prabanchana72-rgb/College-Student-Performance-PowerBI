# 📊 College Education & Student Performance Dashboard

## 📌 Project Overview

This project presents an interactive Power BI dashboard designed to analyze college education and student performance data.

The dashboard provides insights into student academic performance, attendance, satisfaction, internship status, mentoring support, and teaching quality.

## 🎯 Objectives

- Analyze student performance across different departments
- Compare average marks between departments
- Analyze average student attendance
- Understand student satisfaction levels
- Analyze internship status distribution
- Examine mentoring support and student satisfaction
- Analyze teaching quality across different categories
- Use interactive filters to explore the data
